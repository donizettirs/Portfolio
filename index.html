Sales Calendar — Daily Target Tracker

Business question: instead of a flat sales table, could a manager see a whole month of daily performance against target at a single glance?

Live report
  • Each day renders as its own box with a mini progress bar — green if the daily target was hit, red if not
  • A marker line on each bar shows exactly where the target sits, so "close but missed" looks different from "way off"
  • Built entirely with a single calculated DAX measure that generates HTML/CSS on the fly — no external visual needed
CALENDARIO_HTML.dax
-- DAX measure that builds one styled HTML box per calendar day
CALENDARIO_HTML =
VAR MaxSales = MAXX(TABELA_CALENDARIO, [TOTAL_VENDAS])
VAR CSS = "<style>.day-box{border:1px solid #ccc;...}</style>"
RETURN
CSS &
CONCATENATEX(
    ADDCOLUMNS(TABELA_CALENDARIO,
        "BarClass", IF(DIVIDE([TOTAL_VENDAS],[META],0)>=1, "achieved", "not-achieved")
    ),
    "<div class='day-box'>...</div>", ""
)

Sales vs. Regional Socioeconomics

Business question: does customer behavior and sales performance actually track with regional economic conditions — income, unemployment, internet access — or does it just look that way?

Live report
  • Bulk-loaded four raw CSVs — customers, transactions, products, and state-level demographic/economic data — into SQL Server
  • Built a view joining customers to their state's income, unemployment, and internet-access data, with automatic age-bracket and discount-tier logic
  • A second view calculates true unit price per product, category, and sales channel — feeding a dashboard that cross-references sales against the economic backdrop of each region
vw_names.sql
CREATE OR ALTER VIEW VW_NAMES AS
SELECT DISTINCT
    N.NOME, N.ID_CLIENTE, EI.ESTADO, N.IDADE,
    CASE
        WHEN N.IDADE < 13 THEN 'Child'
        WHEN N.IDADE BETWEEN 13 AND 19 THEN 'Teen'
        WHEN N.IDADE BETWEEN 20 AND 59 THEN 'Adult'
        ELSE 'Senior'
    END AS AGE_GROUP
FROM NAMES N
INNER JOIN ESTADOS_INFO EI ON N.ENDERECO = EI.SIGLA
INNER JOIN VENDAS VD ON N.ID_CLIENTE = VD.ID_CLIENTE;
